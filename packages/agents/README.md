# @noticedesk/agents

Python package for agent prompts and orchestration. Empty in Sprint 1 by
design — agent code begins in Sprint 2 (notice parsing) and Sprint 3
(drafting). Don't add agent code here ahead of the sprint contract.

The package exists so that:

1. CI can include this directory in its lint paths once code lands.
2. Imports from `noticedesk_agents` resolve cleanly when Sprint 2 begins.
